REAL ID w Kalifornii — dokumenty i proces

Co przygotować do California REAL ID, jak rozpocząć aplikację online, jakie dokumenty zabrać do DMV i kiedy REAL ID jest potrzebne.

Sprawdzono: 22 września 2026

Odpowiedź w 30 sekund

California REAL ID to prawo jazdy lub ID zgodne z federalnym REAL ID Act. Proces można rozpocząć online, ale trzeba zakończyć go w DMV i przedstawić wymagane dokumenty. Przygotuj dokument tożsamości, wymagane informacje dotyczące Social Security oraz dwa dowody California residency.

Najważniejsze informacje

  • REAL ID nie jest obowiązkowe do prowadzenia samochodu.
  • Do typowych federalnych zastosowań możesz użyć również innego akceptowanego dokumentu, np. paszportu.
  • Przygotuj dwa dowody California residency.
  • Jeśli nazwisko się zmieniło, przygotuj dokumenty łączące nazwiska.
  • AB 60 driver’s license nie jest REAL ID.

Czy naprawdę potrzebujesz REAL ID?

REAL ID jest potrzebne, gdy chcesz używać stanowego DL/ID do zastosowań federalnych objętych REAL ID Act. Można użyć również innego dokumentu akceptowanego federalnie.

Jakie dokumenty przygotować?

California DMV wymaga dokumentu potwierdzającego tożsamość, odpowiedniej dokumentacji lub weryfikacji Social Security oraz dwóch dowodów California residency.

Sprawdź zgodność nazwiska

Jeśli nazwisko na dokumencie tożsamości różni się od obecnego nazwiska, przygotuj dokumenty tworzące pełne połączenie między nazwiskami.

Co można zrobić online?

DMV pozwala rozpocząć aplikację i przesłać dokumenty do wstępnego sprawdzenia online, ale proces wymaga zakończenia zgodnie z instrukcją DMV.

REAL ID a AB 60

AB 60 i REAL ID to odrębne dokumenty. AB 60 nie jest REAL ID.

Proces krok po kroku

  1. Otwórz checklistę REAL ID.
  2. Zbierz dokumenty, w tym dwa dowody adresu.
  3. Rozpocznij aplikację online.
  4. Zakończ proces w DMV.
