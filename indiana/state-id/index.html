Indiana ID — dokumenty, opłata i bezpłatne ID

Jak uzyskać Indiana identification card: wymagane dokumenty, opłata $9, free voter ID i replacement.

Sprawdzono: 22 września 2026

Odpowiedź w 30 sekund

Indiana identification card może otrzymać resident w dowolnym wieku, który nie posiada driver’s license. Nie można jednocześnie posiadać ID card i driver’s license. Standardowa opłata za initial, renewal, amended lub replacement ID wynosi $9.

Najważniejsze informacje

  • ID może być wydane Indiana resident w dowolnym wieku.
  • Nie można jednocześnie mieć ID i driver’s license.
  • Standardowa opłata: $9.
  • Free ID może być dostępne dla U.S. citizen 18+ eligible to vote.
  • Potrzebne: identity, lawful status, SSN i dwa proofs of Indiana residency.

Dla kogo jest Indiana ID?

To stanowy photo identification credential dla osób, które nie potrzebują prawa jazdy.

Dokumenty

BMV wymaga original lub certified copies dokumentów: proof of identity, lawful status, Social Security number oraz dwóch proofs of Indiana residency.

Opłata i bezpłatne ID

BMV podaje $9 za initial, renewal, amended albo replacement identification card. Free ID może być wydane, jeśli masz co najmniej 18 lat, jesteś U.S. citizen i jesteś eligible to vote.

Replacement

Standardowe ID można w wielu przypadkach zastąpić online, przez BMV Connect kiosk albo w branch.
