Pennsylvania Photo ID — dokumenty, opłaty i wniosek

Jak uzyskać stanowy Photo ID w Pensylwanii: kto może dostać kartę, wymagane dokumenty, proces, aktualne opłaty i różnica między standard ID a REAL ID.

Sprawdzono: 22 września 2026

Odpowiedź w 30 sekund

Pennsylvania Photo ID to stanowy dokument tożsamości, a nie prawo jazdy. PennDOT wydaje go mieszkańcom Pensylwanii od 10. roku życia. Pierwszy Photo ID kosztuje obecnie $43.50. Wniosek można rozpocząć na formularzu DL-54A, a dokumenty są weryfikowane przez PennDOT.

Najważniejsze informacje

  • Photo ID może otrzymać mieszkaniec Pensylwanii w wieku co najmniej 10 lat.
  • Photo ID nie daje uprawnień do prowadzenia pojazdu.
  • Initial Identification Card kosztuje obecnie $43.50.
  • Osoby 18+ muszą przedstawić dwa dowody adresu; osoby poniżej 18 lat mają odrębne zasady.
  • Photo ID może być standardowy albo REAL ID-compliant, jeśli spełnisz dodatkowe wymogi REAL ID.

Kto może dostać Pennsylvania Photo ID?

PennDOT wskazuje, że karta Photo ID jest dostępna dla mieszkańców Pensylwanii od 10. roku życia. To rozwiązanie dla osób, które potrzebują stanowego dokumentu ze zdjęciem, ale nie potrzebują prawa jazdy.

Co trzeba przynieść?

Przy pierwszym wniosku przygotuj Form DL-54A, proof of identification, dokumentację Social Security wymaganą przez PennDOT oraz — jeżeli masz 18 lat lub więcej — dwa dowody adresu w Pensylwanii. Jeżeli masz dokument tożsamości lub prawo jazdy z innego stanu, PennDOT może wymagać jego oddania przy wydawaniu Pennsylvania Photo ID.

Proces krok po kroku

  1. Sprawdź aktualną listę dokumentów PennDOT.
  2. Wypełnij Application for Initial Photo Identification Card (DL-54A).
  3. Przedstaw dokumenty w Driver License Center albo postępuj zgodnie z aktualną instrukcją PennDOT dla twojej sytuacji.
  4. Po weryfikacji przejdź do Photo Center.
  5. Zrób zdjęcie i odbierz Photo ID zgodnie z procedurą placówki.

Photo ID i REAL ID to nie to samo

Zwykła Pennsylvania Photo ID potwierdza tożsamość, ale nie musi być federalnie zgodnym REAL ID. Jeżeli chcesz używać karty do celów federalnych wymagających REAL ID, wybierz wersję REAL ID i spełnij dodatkowe wymagania dokumentacyjne.

Bezpłatne ID w szczególnych sytuacjach

PennDOT publikuje również informacje o bezpłatnych dokumentach dla kwalifikujących się osób doświadczających bezdomności. Kryteria i procedura są odrębne od standardowego płatnego Photo ID.
