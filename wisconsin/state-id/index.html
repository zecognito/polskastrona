Wisconsin ID — stanowy dokument tożsamości

Jak uzyskać Wisconsin ID card: dokumenty, opłaty, bezpłatny ID do głosowania, non-expiring ID dla 65+ i REAL ID.

Sprawdzono: 22 września 2026

Odpowiedź w 30 sekund

Każdy resident Wisconsin może ubiegać się o Wisconsin ID card. Nie ma minimalnego wieku, ale nie można jednocześnie posiadać ważnego Wisconsin driver license i Wisconsin ID. Pierwszy ID wymaga wizyty w DMV.

Najważniejsze informacje

  • Brak minimalnego wieku.
  • Nie można mieć jednocześnie Wisconsin driver license i Wisconsin ID.
  • Original ID: $28; renewal: $28; duplicate: $16.
  • ID potrzebne do głosowania może być wydane bez opłaty osobom spełniającym warunki.
  • U.S. citizens 65+ mogą uzyskać non-expiring ID.
  • Fizyczna karta jest wysyłana pocztą; DMV wydaje photo receipt.

Jak dostać pierwszy Wisconsin ID?

Original ID wymaga wizyty w DMV Customer Service Center i formularza MV3004. Trzeba przedstawić proof of name/date of birth, identity, Wisconsin residency, citizenship lub legal status oraz podać Social Security number.

Ile kosztuje ID?

Aktualny WisDOT fee schedule podaje $28 za original 8-year ID, $28 za renewal i $16 za duplicate. ID wydawane do celów wyborczych może być bezpłatne dla kwalifikującej się osoby.

Bezpłatny ID do głosowania

Wisconsin nie ma osobnego „voter ID”. DMV może wydać kwalifikującemu się U.S. citizen bezpłatny Wisconsin ID do głosowania. Jeśli nie masz wszystkich standardowych dokumentów, dostępny jest ID Petition Process, który pozwala rozpocząć weryfikację z dokumentami, które posiadasz.

Non-expiring ID po 65 roku życia

Wisconsin pozwala U.S. citizens w wieku 65+ uzyskać ID bez daty wygaśnięcia. Osoba posiadająca driver license musi zrezygnować z driving privileges, aby otrzymać ID.

Karta pocztą

ID cards są wysyłane pocztą. DMV daje receipt ze zdjęciem, który służy jako tymczasowy ID i jest akceptowany jako photo identification do głosowania. WisDOT zaleca kontakt, jeśli karta nie przyjdzie w ciągu 10 business days.
