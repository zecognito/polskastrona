# PolskaStrona.com

Polskojęzyczny praktyczny przewodnik po życiu w Stanach Zjednoczonych.

## Status

Projekt w budowie. Produkcyjna publikacja i wdrożenie wymagają osobnej akceptacji.

## Zasady projektu

- Polski jest językiem startowym.
- Architektura pozostaje gotowa na późniejsze wersje językowe.
- Treści mają odpowiadać na realne pytania Polaków mieszkających w USA.
- Informacje zmienne w czasie wymagają oficjalnych źródeł i daty weryfikacji.
- Brak cienkich, masowo generowanych stron.
- Czytelność mobilna, szybkość i zaufanie są priorytetami.
