Michigan State ID — dokumenty i opłata $10

Jak uzyskać Michigan state ID: wymagane dokumenty, standard ID za $10, no-fee ID i enhanced ID.

Sprawdzono: 22 września 2026

Odpowiedź w 30 sekund

Standard Michigan state ID kosztuje $10 za first-time, renewal oraz replacement/correction. Część residents może otrzymać no-fee ID, m.in. osoby 65+, legally blind, experiencing homelessness, niektórzy veterans, recipients of state aid oraz osoby z qualifying disability.

Najważniejsze informacje

  • Standard state ID: $10.
  • Enhanced ID: standardowo $30.
  • Wymagane: legal presence, SSN, identity i dwa proofs of Michigan residency.
  • Niektóre grupy kwalifikują się do no-fee ID.
  • Enhanced ID ma dodatkowe funkcje i jest automatycznie REAL ID-compliant.

Dokumenty

Nowy Michigan resident powinien pre-apply, umówić office visit i przynieść proof of legal presence, Social Security number, identity oraz dwa proofs of Michigan residency.

Ile kosztuje ID?

Standard ID kosztuje $10 za first-time, renewal oraz replace/correct. Enhanced ID kosztuje $30; dla osób 65+ lub legally blind enhanced ID może kosztować $20.

No-fee ID

Michigan SOS wymienia kilka kategorii uprawnionych do bezpłatnego standard ID, w tym osoby 65+, legally blind, experiencing homelessness, veterans, recipients of state aid oraz osoby z udokumentowaną disability wpływającą na zdolność bezpiecznego prowadzenia pojazdu.

Enhanced ID

Enhanced Michigan ID jest automatycznie REAL ID-compliant i może służyć do określonych przekroczeń granicy lądowej lub morskiej zamiast U.S. passport, zgodnie z federalnymi zasadami.
